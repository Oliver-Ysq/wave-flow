先把 Wave Flow 跑起来。

推荐方式 · Apple Silicon

终端一键安装

在终端粘贴一行命令：curl 下载不触发 Gatekeeper 隔离标记，装完即可打开，无需任何额外处理。

Terminal 
curl -fsSL https://oliver-ysq.github.io/wave-flow/install.sh | sh
备选 · 手动安装

从源码运行

准备环境，四条命令。

需要 macOS 12+、Bun、Rust 工具链与 Xcode Command Line Tools。首次构建会下载并编译依赖，耗时取决于网络与机器。

  1. 克隆仓库

    Terminal 
    git clone https://github.com/Oliver-Ysq/wave-flow.git
cd wave-flow

  2. 安装依赖

    Terminal 
    bun install

  3. 启动桌面应用

    Terminal 
    bun run desktop:dev

    开发模式会使用独立的窗口配置与 bundle id，不会覆盖正式安装的应用。

  4. 绕过 Gatekeeper 提示（ad-hoc 签名）

    Terminal 
    xattr -dr com.apple.quarantine "/Applications/Wave Flow.app"

    从网上下载的文件会被系统标记隔离属性，未公证的 ad-hoc 应用会报「已损坏」。执行一次后即可正常打开。

  5. 选择本机 CLI

    在设置页选择默认主控，并确保至少一个 CLI 已在本机登录：Codex、DeepSeek Harness 或 Claude Code。Wave Flow 不随包提供模型凭据。

构建应用

打包成可运行的 App。

Terminal 
bun run desktop:build

该命令先编译 Engine sidecar，再执行 Tauri 构建与签名脚本。产物位于 src-tauri/target/release/bundle/。当前 desktop:prepare 只产出 Apple Silicon（aarch64-apple-darwin）的 sidecar；Intel 构建需要另加目标并验证。

关于签名。开发机没有证书时使用 ad-hoc 签名，只保证同一构建内身份一致。正式分发需要单独配置 APPLE_SIGNING_IDENTITY，并验证 hardened runtime、Bun JIT entitlement 与公证。
