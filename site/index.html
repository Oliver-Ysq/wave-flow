AI Agent 工作流 · 本机运行

AI 长任务，
按流程执行，
凭证据交付。

方案先经你确认，再由 Codex、Claude Code 等 Agent CLI 分阶段执行。也可以直接选内置的深度调研或深度代码审查预置开始。中断可以恢复，需要你时 Agent 会显式停下来。

快速开始 去下载

低幻觉交付

「完成」要经过结构校验并写入执行记录；内置的深度调研与深度审查要求每条结论都带原文证据，并由另一个 Agent 独立复核，一句自信的总结不算数。

可恢复的长任务

关窗不停止，重启后显式恢复；只复用严格匹配的已完成部分，不回滚、不悄悄重跑。

脚本化执行

阶段、并行与完成条件写在 TypeScript 里，编排漂移由结构兜底，不靠模型记住计划。主控生成的方案与你手写的文件是同一种模块，可保存接管后继续改。

人工介入

子代理需要输入时显式停下来等你，答案交回原 Agent 继续判断；随时可暂停或停止。
